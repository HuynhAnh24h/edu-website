Phần 1: Hướng dẫn Kích hoạt Đăng nhập Google & Facebook (Chuẩn Production)

Mất khoảng 5–10 phút • Bấm Copy tránh gõ sai

1 Tạo khóa Google OAuth 2.0 trên Google Cloud Console

  1. Truy cập console.cloud.google.com → tạo Project mới tên EduK12 Open.
  2. Vào Google Auth Platform → Branding / Audience (hoặc APIs & Services → OAuth consent screen):
    • Chọn loại người dùng: External.
    • Tên ứng dụng: EduK12 Open, nhập Gmail hỗ trợ của bạn.
    • Điền sẵn 2 đường dẫn bắt buộc đã tạo trên website:
      https://eduk12-scale.eduk12-scale.workers.dev/chinh-sach-bao-mat/
      https://eduk12-scale.eduk12-scale.workers.dev/dieu-khoan/
    • Ở mục Audience, bấm Publish App để mọi học sinh & giáo viên đều đăng nhập được (không bị giới hạn 100 email test).
  3. Vào Clients → Create client (hoặc Credentials → Create Credentials → OAuth client ID) → chọn Web application:
    Authorized JavaScript origins: https://eduk12-scale.eduk12-scale.workers.dev
    Authorized redirect URI: https://eduk12-scale.eduk12-scale.workers.dev/api/v1/auth/oauth/google/callback
  4. Bấm Create → lưu lại 2 mã: Client ID và Client Secret.

2 Tạo khóa Facebook Login trên Meta for Developers

  1. Truy cập developers.facebook.com/apps → bấm Create App.
  2. Chọn mục tiêu Authenticate and request data from users with Facebook Login → đặt tên EduK12 Open.
  3. Vào Use cases → Authentication and account creation → Customize:
    • Bật quyền email và public_profile.
    • Mở mục Settings, dán chính xác dòng sau vào ô Valid OAuth Redirect URIs rồi bấm Save:
      https://eduk12-scale.eduk12-scale.workers.dev/api/v1/auth/oauth/facebook/callback
  4. Vào App settings → Basic:
    • App Domains:
      eduk12-scale.eduk12-scale.workers.dev
    • Privacy Policy URL & User Data Deletion URL: dán link .../chinh-sach-bao-mat/ ở trên.
    • Lưu lại App ID và App Secret (bấm Show để copy).
  5. Gạt công tắc phía trên cùng từ Development sang Live (Công khai).

3 Gắn 4 Secret lên Cloudflare Dashboard (An toàn — Không lộ lên GitHub)

Mở dash.cloudflare.com → Compute (Workers) → Workers & Pages → chọn Worker eduk12-scale → tab Settings → Variables and Secrets → bấm Add (chọn Type: Secret):

Tên biến (Variable Name) Copy nhanh Giá trị dán vào (Value)
GOOGLE_CLIENT_ID Client ID lấy từ Google Cloud (Bước 1)
GOOGLE_CLIENT_SECRET Client Secret lấy từ Google Cloud (Bước 1)
FACEBOOK_APP_ID App ID lấy từ Meta Developers (Bước 2)
FACEBOOK_APP_SECRET App Secret lấy từ Meta Developers (Bước 2)

Sau khi thêm đủ 4 biến, bấm nút Deploy / Save trên Cloudflare là hệ thống kích hoạt ngay lập tức!

4 Kiểm tra Trạng thái OAuth Live trực tiếp

Bấm nút bên trên để kiểm tra trực tiếp máy chủ eduk12-scale.eduk12-scale.workers.dev xem đã nhận đủ khóa Google & Facebook hay chưa.

Google OAuth 2.0
Chưa kiểm tra — bấm nút trên
Facebook OAuth 2.0
Chưa kiểm tra — bấm nút trên

Bảng xử lý nhanh lỗi thường gặp

Thông báo lỗi Nguyên nhân Cách sửa trong 30 giây
Error 400: redirect_uri_mismatch URL Callback dán trên Google/Facebook bị thiếu chữ hoặc dư dấu / ở cuối. Copy lại đúng link ở Bước 1 / Bước 2 dán đè vào mục Redirect URI và bấm Save.
Access blocked: App has not completed verification App Google đang ở chế độ Testing mà chưa thêm email hoặc chưa Publish. Vào Google Auth Platform → Audience → bấm Publish App.
App Not Setup / Facebook Login unavailable App Facebook đang ở chế độ Development. Điền đủ Privacy Policy URL rồi gạt nút trên cùng sang Live.
Vẫn thấy chữ Setup trên nút Google/FB Chưa bấm Deploy / Save sau khi thêm Secret trên Cloudflare. Kiểm tra lại đúng chính tả 4 tên biến ở Bước 3 rồi bấm Deploy.
